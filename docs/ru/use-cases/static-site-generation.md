# Улучшение производительности статической генерации сайта (SSG)

Даже если вы не планируете запускать Nuxt как сервер, вы все равно можете использовать этот модуль, особенно если у вас много страниц.

При генерации 5000 статических страниц обычно меняется только содержимое страницы. Хедер, навигация и футер в основном одинаковые. Используя компонент [`<RenderCacheable>`](/ru/features/component-cache), вы можете кешировать отрендеренную разметку компонента. Это означает, что при генерации 5000 страниц навигация и футер генерируются только один раз. После этого разметка используется напрямую.

Если вы используете внешний backend кеша, такой как Redis, вы даже можете кешировать эти компоненты между несколькими выполнениями SSG.

Также возможно использовать [`<RenderCacheable>`](/ru/features/component-cache) для кеширования разметки целых страниц при использовании внутри layout компонента. Это означает, что если вам нужно регенерировать страницы, вам нужно сгенерировать только те, которые фактически изменились.

В зависимости от вашего проекта это может значительно улучшить время, необходимое для генерации страниц.

Преимущества заметны тем больше, чем больше у вас страниц и сложных компонентов. Это означает, что преимущества будут едва заметны, если у вас всего 50 страниц.
