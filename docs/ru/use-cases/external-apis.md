# Внешние API

Работа с внешними API может быть непредсказуемой. Они могут быть ненадежными или просто медленными. Используя [data cache](/ru/features/data-cache), вы можете кешировать ответы бессрочно или на фиксированное время и в зависимости от вашего случая значительно улучшить время отклика вашего приложения.

Или, возможно, у вас есть ограничения по количеству запросов или вы платите за запрос к API. Если данные не меняются часто, то эта функция для вас.
