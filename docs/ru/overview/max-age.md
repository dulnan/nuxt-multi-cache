# Max Age

Все кеши поддерживают установку _max age_ для элементов кеша. Это может быть либо абсолютное значение, например `60`, либо относительное, например `'midnight'`. После истечения max age элемент кеша будет ревалидирован.

## Числовая абсолютная длительность

Абсолютное значение - это просто число в секундах, например `120`, означающее 2 минуты. Кешированный элемент истечет ровно через 120 секунд, начиная с момента запроса.

## Именованная абсолютная длительность

Для лучшей читаемости кода вы также можете использовать любую из именованных абсолютных длительностей, определенных в [type.NamedDurations], например:

- `'5m'` - Кешировать на 5 минут
- `'1h'` - Кешировать на 1 час
- `'12h'` - Кешировать на полдня
- `'2d'` - Кешировать на 2 дня
- `'7d'` - Кешировать на неделю

## Именованный относительный интервал

Вы также можете использовать любой из _именованных интервалов_, определенных в [type.NamedInterval]. Они автоматически вычислят правильный max age, например:

- `'next-hour'` - Будет кешировать до конца текущего часа (например, если текущее время `11:30:00`, вычислит max age `1799`, чтобы элемент инвалидировался точно в `11:59:59`)
- `'midnight'` - Будет кешировать до полуночи текущего дня (например, `23:59:59`)

## Специальные строки

Также есть две специальные строки, которые можно использовать:

- `'permanent'` - Будет кешировать без max age. Это равносильно отсутствию max age.
- `'never'` - Вообще не будет кешировать.

## Специальные числа

Следующие два числа имеют "специальное" (но интуитивное) значение:

- `-1` - Будет кешировать без max age. Это равносильно установке `'permanent'` или отсутствию max age вообще.
- `0` - Вообще не будет кешировать. Равносильно установке `'never'`.

## Вычисление времени истечения

Модуль использует единую временную метку для вычисления точного времени истечения элемента кеша. Временная метка определяется при первом взаимодействии с кешем во время запроса и затем сохраняется в контексте события.

Внутренне все значения, связанные со _временем_, хранятся либо как _секунды_ (для всего, что имеет _возраст_), либо как unix timestamp в секундах (для всего, что является конкретным моментом времени).

Например, вы устанавливаете _max age_ как значение в секундах, но внутренне элемент кеша будет иметь свойство `expires`, которое представляет точную временную метку, в которую элемент должен быть ревалидирован.
